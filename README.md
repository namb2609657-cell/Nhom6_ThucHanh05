# ThucHanh05

## 1. Danh sách file

- `index.html`: File HTML của bài thực hành.
- `infographic.png`: Infographic về ứng dụng công nghệ số trong học tập.
- `Video_tao_boi_CapCut_20MB.mp4`: Video minh họa.
- `Báo cáo - Ứng dụng công nghệ số trong học tập.pdf`: Báo cáo của bài thực hành.
- `README.md`: File mô tả nội dung thực hành.

## 2. Nguồn AI

- Canva AI: Sử dụng để hỗ trợ tạo infographic.
- Microsoft Copilot: Sử dụng để hỗ trợ tìm kiếm, xây dựng và chỉnh sửa nội dung.

## 3. Nguồn hình ảnh

- Unsplash: Hình ảnh sử dụng trong infographic.

## 4. Giấy phép

Nội dung và tài nguyên được sử dụng theo giấy phép CC BY, đồng thời ghi rõ nguồn khi sử dụng lại.
